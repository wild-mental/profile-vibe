# EMERITUS — Educator Bio (2026)

Emeritus Executive Education 제출용 **Educator Bio 1페이지** 제작 작업 경로.

## 한 줄 요약

Emeritus가 글로벌 MNC 은행 대상으로 운영하는 **AI Accelerate** 프로그램의 faculty 후보로 등록하기 위한 공식 bio.
당장의 Module 3·4는 일정 불가로 **거절**하되, **Module 6~10의 향후 세션 후보로 남기 위한** 포지셔닝 자료다.

## 착수 전 결정이 필요한 5건

원고 작성을 시작하기 전에 아래가 정해져야 한다. 상세 근거는 `brief.md` § 미해결 이슈.

1. **Current Position 표기** — 템플릿 가이드가 "본인 사업체의 Co-Founder/CEO 류 타이틀"을 명시적으로 지양한다. 현재 서명인 `Principal AI & IT Education Consultant, MakersWorld Inc.`를 그대로 쓸지, 대안 조합으로 갈지 결정 필요. → 후보 3안과 권장안은 `content-map.md` §2.
2. **Videos 3칸** — 템플릿에 "Click to view" 링크 슬롯이 3개이고, 가이드는 "클라이언트가 항상 요청한다"고 못박는다. 현재 보유 영상 자산 미확인.
3. **현재 진행 중인 AI-native PM 과정 (~2026.10.01)** — 이메일에서 일정 거절의 근거로 쓰는 과정인데, `source-docs/`에 해당 기수 기록이 없다. 정확한 과정명·기관·기간 확인 필요. **확인 전에는 bio에 기재하지 않는다.**
4. **Module 5~10 구성** — 이메일에서 Module 6(Change Readiness)·7~10을 특정해 언급하는데, 근거가 되는 learning journey 표는 Neha 메일에 이미지로만 있어 우리 자료에 없다. 원본 확보 또는 주제명 지칭으로 완화 필요.
5. **Alignment call 응답** — Neha가 "introductory alignment call with the client next week" 가능 여부를 물었는데 이메일 초안에 답이 없다. Module 3·4를 거절하더라도 **향후 모듈 논의를 위한 콜에는 응한다**는 한 문장이 다음 기회로 이어지는 실질 장치다. → `outbound-email.md` § 발송 전 확인 사항.
